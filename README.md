# Audio-Equalizer-FPGA

Projekt układu filtrującego audio w oparciu o płytkę Zybo z ukłądem FPGA.
Projekt wykorzystuje Vivado w wersji 2022.2

Opis katalogów:

* `audio_samples` - przygotowane próbki dźwięku na potrzeby demonstracji
* `tools` - biblioteka zawierająca funkcje używane w Jupyter Notebook
* `vivado_project` - folder z projektem Vivado

Domumentacja projektu: [projekt_sdup](projekt_sdup.ipynb)
